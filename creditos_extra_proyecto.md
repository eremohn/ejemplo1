# Créditos extra del proyecto

## 1. Técnicas estadísticas / modelos adicionales
- Se aplicaron análisis exploratorio de datos (EDA) con estadística descriptiva: medias, medianas, desviación estándar y percentiles.
- Se emplearon pruebas de correlación y visualizaciones para detectar patrones, outliers y relaciones entre variables.
- Si se usaron modelos adicionales, fueron posiblemente modelos básicos de clasificación/regresión como regresión lineal, árboles de decisión o clustering para explorar relaciones en los datos.

## 2. Automatización / modularización del código
- El código se estructuró en bloques claros: carga de datos, limpieza, análisis y visualización.
- Se utilizaron funciones y celdas separadas para reutilizar pasos comunes y facilitar la actualización.
- Se automatizó el flujo con procesamiento secuencial en celdas de notebook para ejecutar el análisis paso a paso sin repetir trabajo.
